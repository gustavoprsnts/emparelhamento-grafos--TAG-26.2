# Emparelhamento Estável Máximo: Alocação de Alunos em Projetos

## Objetivos
Implementar uma solução algorítmica e visual para o problema de alocação estável máxima entre 200 alunos e 50 projetos universitários (limite de 80 vagas), respeitando requisitos mínimos de nota agregada, restrições de capacidade (mínimo de 1 aluno por projeto ativo) e listas de preferência bilaterais. O sistema simula tanto a abordagem orientada aos alunos quanto a orientada aos projetos (definida como proposta final), exibindo a evolução do grafo bipartido ao longo de 10 iterações com busca por caminhos alternados.

## Ferramentas
* **Linguagem:** Python 3.x
* **Manipulação de Grafos e Algoritmos:** `networkx` 
* **Visualização Gráfica:** `matplotlib` 
* **Manipulação de Dados e Saída Tabular:** `pandas` / `tabulate`
* **Base Teórica:** Algoritmo de Gale-Shapley
